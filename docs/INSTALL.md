# Установка

## Готовый пакет Windows

Нужны Windows 10/11, обычный настольный Discord и установленный [Vencord](https://vencord.dev/download). Git, Node.js и Python не нужны.

1. Скачайте архив установщика из [последнего релиза](https://github.com/EnroXD1/WinYandexMusicRPC-Vencord/releases/latest).
2. Распакуйте **всю папку**. Не запускайте скрипт прямо из окна архиватора.
3. Запустите `INSTALL.cmd`, прочитайте описание и нажмите Enter.
4. Установщик проверит контрольные суммы, подключение Discord к стандартной папке Vencord, завершит Discord и сохранит прежнюю сборку перед заменой.
5. После запуска Discord включите **WinYandexMusicRPC** в **Настройки → Vencord → Plugins**.
6. Разрешите показ активности в обычных настройках Discord.

Если работает отдельная WinYandexMusicRPC.exe, завершите её, чтобы не публиковать вторую музыкальную активность.

## Что делает установщик

- Меняет только runtime-папку `dist` стандартного Vencord.
- Создаёт проверяемую резервную копию в `%APPDATA%\Vencord\wymrpc-backups`.
- Сохраняет настройки, темы и файл зашифрованного токена.
- В случае ошибки после замены пытается вернуть предыдущую сборку.
- Перезапускает тот клиент Discord, который закрывал, либо единственный подходящий клиент, если Discord был закрыт.

Это готовая **сборка Vencord с пользовательским плагином**. Другие сторонние плагины прежней сборки не объединяются с ней автоматически. Автообновление Vencord отключено; новые версии устанавливаются новым пакетом.

## Проверка и восстановление

`CHECK.cmd` проверяет файлы и путь подключения Discord без установки и закрытия приложений.

`RESTORE.cmd` возвращает сборку, сохранённую перед последней установкой. Сборка, заменяемая восстановлением, также сохраняется. При повторной установке идентичной версии файлы не меняются и резервная копия не перезаписывается.

Если автоматический откат не завершился, оставьте Discord закрытым и используйте **Repair** официального установщика Vencord. Repair возвращает обычный Vencord и убирает пользовательскую сборку.

## Поддерживаемые клиенты

Поддерживаются Discord Stable, PTB, Canary и Development, установленные обычным способом и подключённые к `%APPDATA%\Vencord`.

Установщик не настраивает Microsoft Store, переносимые установки, нестандартные пути Vencord и Vesktop. Для собственного checkout или Vesktop воспользуйтесь [сборкой из исходников](DEVELOPMENT.md). На Windows Vesktop можно направить на папку `dist` своей сборки через **Vencord Location**; этот вариант не проверялся в живом клиенте.

## Выбор источника

**Windows:** выберите «Приложения и браузеры Windows» и полностью перезапустите Discord. Системный медиаплеер должен публиковать текущий трек. В фильтре используйте имя найденного приложения; пустой фильтр разрешает все сессии, в том числе видео в браузере.

**Ynison:** выберите источник аккаунта Яндекс Музыки, сохраните [OAuth-токен](AUTH.md), включите музыку на устройстве с тем же аккаунтом. Discord должен оставаться запущенным на ПК.

При изменении native-кода или источника полностью закройте Discord, включая значок в трее, и откройте снова.
