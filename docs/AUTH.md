# OAuth-токен Яндекс Музыки

Токен нужен для источника **Ynison**. Режим медиаплееров Windows работает без него.

## Получить токен

Актуальные способы описаны в [документации Yandex Music API](https://ym.marshal.dev/token/).

Для способа через браузер:

1. Откройте [страницу авторизации Яндекса](https://oauth.yandex.ru/authorize?response_type=token&client_id=23cabbbdc6cd418abb4b39c32c41195d).
2. Войдите в аккаунт, на котором слушаете музыку, и подтвердите доступ.
3. После перенаправления скопируйте значение `access_token` из адреса — часть после `access_token=` и до следующего `&`.
4. Вставьте **только токен** в настройки WinYandexMusicRPC и нажмите **«Сохранить токен»**.

Если адрес слишком быстро меняется, документация рекомендует заранее включить замедление сети в DevTools браузера.

Пароль от аккаунта вводить в плагин не нужно. Поле очищается после сохранения. Токен хранится отдельно от синхронизируемых настроек, с системным шифрованием. Кнопка **«Удалить токен»** удаляет сохранённый файл.

## Проверить авторизацию

Нажмите **«Проверить токен»**. Плагин отправит один запрос на фиксированный endpoint API Яндекс Музыки и покажет результат без токена, логина или идентификатора аккаунта.

| Результат | Что означает |
|---|---|
| Токен принят | API Яндекс Музыки подтвердил авторизованный аккаунт |
| HTTP 401 | API не принял токен; сохраните новый |
| HTTP 403 | API запретил доступ; проверьте права токена и аккаунт |
| Ошибка сети / TLS | Проверка авторизации не завершена |

Состояние Ynison отображается отдельно. Его диагностика показывает этап и безопасные коды HTTP/gRPC; любая ошибка сервиса не приравнивается к истечению токена.

Токен не обновляется автоматически. По истечении срока получите новый и сохраните его. При отправке отчёта об ошибке достаточно текста диагностики и версии плагина — токен публиковать не нужно.
