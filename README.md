## Возможности

| | Что умеет плагин |
|---|---|
| 🎵 Активность Discord | Статус «Слушает», название трека, исполнитель и альбом |
| ⏱️ Воспроизведение | Прогресс, перемотка, пауза и настраиваемое скрытие статуса |
| 🖥️ Windows | Приложение Яндекс Музыки, браузеры и другие плееры, передающие медиаданные системе |
| 📱 Ynison | Получение состояния аккаунта Яндекс Музыки с телефона и других устройств |
| 🖼️ Обложки и ссылки | Каталог Яндекса в Ynison; необязательный поиск обложек iTunes в Windows |
| 🔐 Токен | Системное шифрование, отдельная проверка авторизации и безопасные коды ошибок |
| 📦 Установка | Готовая сборка с `INSTALL.cmd`, резервной копией и `RESTORE.cmd` |

## Установка за несколько шагов

1. Установите обычный [Vencord](https://vencord.dev/download), если ещё не используете его.
2. Откройте **[Releases](https://github.com/EnroXD1/WinYandexMusicRPC-Vencord/releases/latest)** и скачайте `WinYandexMusicRPC-Installer-1.0.1.zip`.
3. Полностью распакуйте архив и запустите **`INSTALL.cmd`**. Подтвердите установку клавишей Enter.
4. После открытия Discord перейдите в **Настройки → Vencord → Plugins → WinYandexMusicRPC** и включите плагин.
5. Разрешите показ текущей активности в обычных настройках конфиденциальности Discord.

**Для готового установщика не нужны Git, Node.js или Python.** Он рассчитан на Windows 10/11 и стандартную установку Vencord в `%APPDATA%\Vencord`.

Установщик заменяет сборку Vencord целиком. Другие сторонние плагины из предыдущей сборки автоматически не переносятся. Предыдущая сборка сохраняется для отката, настройки и темы остаются на месте. **`RESTORE.cmd`** возвращает сборку, сохранённую перед последней установкой. [Подробная инструкция →](docs/INSTALL.md)

## Выберите источник музыки

### На компьютере

Выберите **«Приложения и браузеры Windows»**, полностью перезапустите Discord и запустите воспроизведение. Токен для этого режима не требуется. В настройках плагина отображаются найденные медиаплееры; по их имени можно задать фильтр, например `yandex`.

### На телефоне или другом устройстве

Выберите **«Аккаунт Яндекс Музыки / телефон (Ynison)»**, сохраните OAuth-токен своего аккаунта и запустите музыку на устройстве с тем же аккаунтом. Кнопка **«Проверить токен»** отдельно проверяет авторизацию в API Яндекс Музыки. [Как получить токен →](docs/AUTH.md)

Discord с плагином должен оставаться запущенным на компьютере при использовании любого источника. Это плагин для настольного клиента, а не модификация Discord для Android или iOS.

## Настройка

| Параметр | Назначение |
|---|---|
| Источник | Медиаплееры Windows или аккаунт Яндекс Музыки / Ynison |
| Фильтр приложения | Часть системного имени плеера; пусто — разрешить все медиасессии |
| Приоритет Яндекса | Выбор Яндекс Музыки среди одновременно играющих приложений |
| Пауза | `30` — скрыть через 30 секунд, `0` — сразу, `-1` — оставлять на паузе |
| Название активности | Подстановки `{title}`, `{artist}`, `{album}` |
| Список участников | Показывать название активности, трек или исполнителя |
| Обложка / кнопка | Включение обложки и ссылки на трек |
| Application ID | Собственное Discord-приложение или публичный ID исходной утилиты |

Изменение источника требует полного перезапуска Discord. При неизвестной длительности или скорости, отличной от 1×, таймер скрывается.

## Конфиденциальность

OAuth-токен сохраняется в зашифрованном виде через Electron `safeStorage` / Windows DPAPI и не попадает в обычные синхронизируемые настройки Vencord. Плагин не возвращает токен в интерфейс и не включает его в сообщения диагностики.

В режиме Windows поиск обложек отправляет название и исполнителя в iTunes; его можно отключить. В Ynison используются сервисы Яндекса. [Что и куда отправляется →](docs/PRIVACY.md)

## Для разработчиков

Исходники плагина находятся в [`winYandexMusicRPC.desktop/`](winYandexMusicRPC.desktop), установщика — в [`installer/`](installer). Проверенная база: **Vencord 1.15.15**, коммит `8d64c8be7e68616f8f116a6fff9480051aa2a0c5`.

Для полной проверки, сборки и упаковки на Windows с установленными Git, Node.js 24 и pnpm:

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File .\scripts\Build.ps1 -Package
```

Скрипт готовит отдельную рабочую копию Vencord в `work/`, устанавливает зависимости, запускает проверки и собирает архив в `out/`. Установленный Discord при этом не изменяется. [Разработка и проверка →](docs/DEVELOPMENT.md)

GitHub Actions проверяет изменения в `main` и pull request. Тег вида `v1.0.1` запускает сборку установщика и публикацию релиза.

## Важные особенности

- Vencord подключает сторонние плагины через собственную сборку; формат BetterDiscord `.plugin.js` здесь не используется.
- В готовой сборке отключено автообновление Vencord, чтобы оно не убрало пользовательский плагин. Обновление — установкой новой версии пакета.
- Windows-плеер должен передавать системные медиаданные. По системному имени браузера нельзя отличить отдельные вкладки.
- Ynison — неофициальный интерфейс Яндекса; его поведение зависит от сервиса и устройства. Офлайн-устройства и локальные файлы могут не предоставлять подходящее состояние.
- Обложка в режиме Windows находится не для каждого трека. Кнопки собственной активности могут не отображаться в вашем просмотре профиля.
- Работа с настольными медиасессиями Windows проверена. Для Ynison есть протокольные и регрессионные тесты; они не заменяют проверку на конкретном аккаунте и устройстве.
