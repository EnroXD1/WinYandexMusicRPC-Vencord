WinYandexMusicRPC 1.0.1 — установочный пакет для Vencord

Быстрая установка

1. Полностью распакуйте архив в отдельную папку.
2. Если обычный Vencord ещё не установлен, установите его через
   https://vencord.dev/download . Если установлен — пропустите этот шаг.
3. Дважды нажмите INSTALL.cmd. Проверьте описание и нажмите Enter.
4. Дождитесь сообщения «Готово». Discord откроется снова.
5. Откройте Настройки → Vencord → Plugins, найдите WinYandexMusicRPC
   и включите переключатель.

Git, Node.js, Python и сборка на вашем компьютере не нужны.
Запуск от администратора обычно не требуется.

Установщик заменяет сборку Vencord целиком. Другие сторонние плагины
текущей сборки, в том числе Orion, не включены в этот пакет. Их сборка
сохраняется в резервной копии. Обычные настройки Vencord, темы и токены
установщик не изменяет.

Музыка на телефоне

В настройках плагина выбран источник Ynison. Добавьте OAuth-токен своего
аккаунта Яндекс Музыки кнопкой «Сохранить токен», затем запустите музыку
на телефоне с тем же аккаунтом. Discord должен оставаться запущенным на ПК.
Пароль от Яндекса в плагин вводить не нужно.

Если показана ошибка, нажмите «Проверить токен» в настройках плагина.
Кнопка отдельно проверяет авторизацию в API Яндекс Музыки и не показывает
сам токен или данные аккаунта. HTTP 401 означает, что API не принял токен;
HTTP 403 — доступ запрещён. Если токен принят, смотрите отдельный код
ошибки Ynison в верхней части настроек.

В версии 1.0.1 исправлен формат регистрации Ynison: используется текущая
схема SDK, удалено неподдерживаемое поле is_shadow. Исправлена диагностика:
ошибка формата запроса больше не называется ошибкой срока действия токена.
При обновлении уже сохранённый токен остаётся на месте.

Получение токена:
https://ym.marshal.dev/token/#через-браузер-implicit-oauth

Музыка в приложении Windows

В настройках плагина выберите источник «Приложения и браузеры Windows»
и полностью перезапустите Discord. Токен для этого режима не нужен.
Плагин использует скрытый Windows PowerShell и завершает его при отключении.

В Discord должна быть разрешена передача текущей активности.
Настройки конфиденциальности активности находятся в обычных настройках Discord.

Восстановление

Запустите RESTORE.cmd и нажмите Enter. Он вернёт сборку, сохранённую
перед последней установкой этого пакета. Сборка, которую заменяет
восстановление, тоже сохраняется в отдельной резервной копии.

Копии хранятся здесь:
%APPDATA%\Vencord\wymrpc-backups

Старую папку dist.orion-backup этот установщик не изменяет.
При повторном запуске той же установленной версии новая копия не создаётся.

Проверка без установки

CHECK.cmd проверяет комплектность пакета и подключение Discord к Vencord.
Он ничего не устанавливает и не закрывает Discord.

Если появилась ошибка

• «Сначала установите Vencord» — установите его официальным установщиком.
• «Не найден Discord» — выполните Install/Repair в официальном установщике
  Vencord для используемого клиента. Сборки из другой папки этот пакет
  намеренно не перезаписывает.
• «Discord сейчас обновляется» — дождитесь завершения обновления.
• «Файл повреждён» — заново распакуйте полный архив.
• При ошибке после замены файлов установщик пытается вернуть старую сборку.
  Если он сообщил, что откат не завершён, оставьте Discord закрытым
  и выполните Repair через официальный установщик Vencord.

Поддерживаются обычные установки Discord, PTB, Canary и Development
на Windows 10/11 с Vencord в стандартной папке %APPDATA%\Vencord.
Microsoft Store, переносимые клиенты, другие пути Vencord и Vesktop
этим установщиком не настраиваются.

Автообновление Vencord в этой готовой сборке отключено, чтобы обновление
не удаляло пользовательский плагин. Для обновления нужен новый пакет
или самостоятельная сборка. Кнопка Repair официального установщика
возвращает обычную сборку Vencord и убирает этот пользовательский плагин.

Проверки

Проверены установка и восстановление в тестовых папках, резервные копии,
откат при повреждении файлов, контрольные суммы, пути с кириллицей/пробелами,
выбор версии Discord и защита от junction-перенаправлений.
Установленный Discord на компьютере при подготовке пакета не изменялся.
Отображение активности в живом Discord и подключение телефона к вашему
аккаунту по-прежнему нужно проверить после установки.

Исходники и лицензии

В SOURCE.zip находятся исходники сборки Vencord с плагином, скрипты
сборки и точные файлы зависимостей. В licenses — лицензии компонентов.
Скрипты установщика и их тесты находятся рядом с этим README.
BUILD-INFO.json содержит версию исходников и параметры сборки.

Это пользовательская сборка, не официальный релиз Discord, Vencord или Яндекса.
