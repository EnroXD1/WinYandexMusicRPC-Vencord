# Конфиденциальность

## Что хранится локально

- Настройки интерфейса и активности — в обычных настройках Vencord.
- OAuth-токен — в `settings/winyandexmusicrpc-token.bin` внутри папки данных Vencord, зашифрованный через Electron `safeStorage` / Windows DPAPI.
- Кратковременный кэш метаданных и обложек — в памяти процесса.
- Резервные копии установщика содержат runtime-файлы Vencord, а не каталог пользовательских настроек.

Токен не возвращается native-методами в интерфейс. После сохранения поле ввода очищается. Диагностика не выводит токен, OAuth-заголовок, логин или идентификатор аккаунта.

## Сетевые обращения

| Функция | Получатель | Данные |
|---|---|---|
| Ynison | Сервисы Яндекса | OAuth-заголовок, идентификатор устройства, регистрация пассивного клиента |
| Данные трека | `api.music.yandex.net` | OAuth-заголовок и идентификатор трека |
| Проверка токена | `api.music.yandex.net/account/status` | OAuth-заголовок |
| Обложка в Windows | `itunes.apple.com` | Название трека и исполнитель; функцию можно отключить |
| Активность и изображения | Discord | Информация, которую вы включили для публикации в профиле |

Плагин не скачивает аудиофайлы и не отправляет команды управления воспроизведением. Регистрация Ynison использует пассивного клиента, который не становится активным плеером.

Переадресация Ynison ограничена HTTPS/WebSocket-сервисами Яндекса; OAuth-токен не передаётся на произвольный хост из ответа. Обложки внешнего каталога также проходят проверку домена.

## Режим Windows

Скрытый процесс Windows PowerShell читает системные медиасессии. Он запускается плагином и завершается при его отключении. Фильтр приложения позволяет ограничить выбранный источник; пустой фильтр допускает любую медиасессию, включая видео в браузере.

## Диагностика и GitHub

Публикуйте только версию, выбранный источник и безопасное сообщение об ошибке. OAuth-токен, файл `.bin`, пользовательские настройки и личные скриншоты не нужны для воспроизведения протокольных ошибок. Репозиторий и установочные архивы не содержат пользовательских учётных данных.
